## 本地复现

```sh
npm ci
npm test
npm run test:cloudbase
npm run test:rls
npm run build
npm run typecheck
```

构建生成 Next.js 类型后再运行类型检查。以上数据库测试在本地隔离执行，不需要真实云凭据，不会修改线上私人数据。国内静态构建可运行 `npm run build:domestic-preview`；连接自己的环境时设置 `.env.local` 中的公开环境标识。
